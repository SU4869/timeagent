隐私政策

更新日期：2026 年 8 月 11 日　·　生效日期：2026 年 8 月 11 日

一、我们是谁

本隐私政策适用于「TimeAgent · 智能时间管家」（以下简称"本应用"）。本应用是一款个人时间管理工具，为您提供日程记录、统计分析及可选的 AI 时间规划功能。

二、我们收集哪些信息

本应用坚持"本地优先"原则，我们不收集、不上传您的个人数据。具体如下：

  • 日程数据：您输入的日程、分类、统计信息，仅保存在您设备本地的存储空间（localStorage）中，不会上传到任何服务器。
  • API Key：如果您自愿在设置中填写大模型 API Key，该 Key 仅保存在您的设备本地，仅用于向您指定的第三方大模型服务发起您主动触发的 AI 请求。
  • 使用数据：本应用不包含任何广告、统计或追踪类 SDK，不收集设备标识、位置、通讯录、相册等敏感信息。

三、我们如何使用信息

  • 日程数据仅用于在您的设备上展示与统计分析，供您本人使用。
  • 当您主动使用"AI 时间规划"功能并已配置 API Key 时，仅将您当次输入的规划需求发送至您指定的大模型服务以获取建议。

四、权限说明

  • 网络权限：用于加载应用内容及您主动触发的 AI 请求。
  • 通知权限（可选）：用于提醒服务；您可以在系统设置中随时关闭，不影响核心功能。

五、数据存储与安全

所有数据均存储于您的设备本地。删除数据的方式：在应用内使用"数据备份/清空"功能，或直接清除应用数据、卸载本应用，数据即被删除。

六、第三方服务

AI 规划功能可能调用您自行配置的第三方大模型服务。该服务的数据处理规则以其自身的隐私政策为准，请您在使用前阅读。除您主动配置外，本应用不集成任何第三方 SDK。

七、未成年人保护

本应用面向一般用户。若您为未成年人，请在监护人指导下使用。

八、政策更新

我们可能适时更新本政策，更新后将在应用内公布。重大变更会以显著方式通知您。

九、联系我们

如您对本政策有任何疑问，可通过应用内「帮助与反馈」页面与我们联系。
